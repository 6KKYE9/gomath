# gomath —— 命令行小数学工具

计算器：支持四则运算表达式求值，以及几个常见数学函数。

## 编译与运行

```powershell
go run . calc "(2+3)*4"     # 表达式求值，支持 + - * / 和括号，支持小数
go run . prime 17           # 判断质数
go run . fib 10             # 第 10 个斐波那契数
go run . fact 5             # 5 的阶乘（用 math/big，大数不溢出）
go run . gcd 12 18          # 12 和 18 的最大公约数
go run . lcm 4 6            # 4 和 6 的最小公倍数
go run . comb 10 3          # 组合数 C(10,3)
go run . sqrt 144           # 平方根 = 12
go run . pow 2 10           # 2 的 10 次方 = 1024
```

`calc` 的参数里如果有空格，可以分开写：`go run . calc 2 + 3`，程序会自动拼起来。

## 子命令

| 子命令 | 示例 | 说明 |
|--------|------|------|
| `calc` | `calc "(1+2)*3"` | 四则运算，支持括号与小数，含除零/括号不匹配报错 |
| `prime` | `prime 17` | 判断是否为质数 |
| `fib` | `fib 10` | 第 n 个斐波那契数（从 0 开始） |
| `fact` | `fact 5` | n 的阶乘（math/big，大数不溢出） |
| `gcd` | `gcd 12 18` | 最大公约数（辗转相除法） |
| `lcm` | `lcm 4 6` | 最小公倍数 |
| `comb` | `comb 10 3` | 组合数 C(n,k)（math/big，大数不溢出） |
| `sqrt` | `sqrt 144` | 平方根 |
| `pow` | `pow 2 10` | 整数幂（底数^指数） |

## 表达式是怎么算出来的

`calc` 用"递归下降"解析：先按 `+ -` 拆成项，项里再按 `* /` 拆成因子，因子可以是数字、带括号的子表达式、或一元负号。这是编译原理里最清楚的写法，比用一堆正则替换靠谱，注释里逐行标了。

## 示例输出

```text
(2+3)*4 = 20
17 是质数? true
fib(10) = 55
5! = 120
gcd(12, 18) = 6
lcm(4, 6) = 12
C(10, 3) = 120
```
